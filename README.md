**MagnetLinker** is a lightweight Windows system tray application that seamlessly integrates with qBittorrent's Web API. It automatically detects magnet links in your clipboard and allows you to quickly categorize downloads as either movies or series, directing them to their respective directories in qBittorrent.

Key Features:

- Automatic magnet link detection from clipboard
- Smart content categorization (Movies/Series)
- Remembering your choices temporarily or indefinitely
- System tray integration for easy access
- Direct torrent file support
- Configurable download directories
- Secure credential management for qBittorrent Web UI

This tool streamlines your downloading workflow by eliminating the need to manually copy-paste magnet links and set download locations in qBittorrent.
